# יום טוב

צ'קליסט יומי לתקופת מילואים. PWA — מתקינים למסך הבית של האייפון, עובד מלא אופליין.

- `index.html` / `app.js` / `styles.css` — האפליקציה (ללא build)
- `sw.js` — service worker (network-first, נופל למטמון אופליין)
- `manifest.webmanifest`, `icons/` — התקנה למסך הבית

הנתונים נשמרים מקומית במכשיר (localStorage). ייצוא CSV/JSON ממסך ההגדרות.

## גמד וענק — `gamad/`

הגרלה משפחתית סודית. כל אחד רואה רק את הענק שלו; גם המארגן לא יודע מי קיבל את מי.

1. המארגן פותח `gamad/`, מכניס רשימת שמות ושולח קישור הצטרפות לקבוצה.
2. כל משתתף בוחר את שמו וקוד סודי (PIN). הטלפון יוצר זוג מפתחות; המפתח הפרטי נשמר רק בו, מוצפן ב-PIN.
   המשתתף שולח למארגן "קוד הרשמה" (מפתח ציבורי בלבד).
3. אי אפשר להגריל עד שכולם נרשמו. ההגרלה היא סבב יחיד: כל אחד נותן לאחד ומקבל מאחד, אף אחד לא מקבל את עצמו.
   שם הענק מוצפן למפתח הציבורי של כל משתתף (ECDH P-256 + AES-GCM, אורך קבוע); ההגרלה עצמה לא מוצגת ולא נשמרת.
4. קישור תוצאות אחד לכולם — כל אחד מפענח רק את השורה שלו, בטלפון שבו נרשם, עם ה-PIN.

דורש https (WebCrypto). אין שרת — הכל רץ בדפדפן.
